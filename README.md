# 🛒 רשימת הקניות שלנו

רשימת קניות משותפת לשני משתמשים. האפליקציה רצה על **GitHub Pages**, והרשימה נשמרת בקובץ `data/list.json` בתוך הריפו הזה. אין שרת ואין מסד נתונים.

## מה יש באפליקציה
- **השלמה אוטומטית**: כ-550 מוצרים נפוצים מהסופר, כולל מותגים (הקובץ `products.json`). מוצר חדש שמוסיפים נשמר ויוצע בפעם הבאה.
- **כמות** לכל מוצר (− / +), **מחיקה** עם אפשרות "ביטול".
- **מיון לפי מחלקות בסופר**: אפשר להחליף מחלקה בלחיצה על האייקון.
- **🛒 הגעתי לסופר**: מושך את הרשימה העדכנית. לחיצה על מוצר מסמנת אותו בקו מחיקה ומורידה אותו לתחתית, לקטע "בעגלה". בסוף לוחצים "סיימתי" והמוצרים שנאספו נמחקים.
- **עובד גם בלי קליטה**: השינויים נשמרים בטלפון ונשלחים כשהחיבור חוזר.
- **סנכרון בין שני הטלפונים**: גם אם שניכם מעדכנים באותו זמן, השינויים מתמזגים.

## הפעלה (פעם אחת)
1. **Settings → Pages**: בשדה Source בוחרים `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`, ולוחצים Save.
   אחרי דקה-שתיים האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/shopping-list/`
2. **יצירת טוקן**: נכנסים ל-github.com/settings/personal-access-tokens/new
   - Token name: `shopping-list`
   - Expiration: אפשר לבחור תוקף ארוך (למשל שנה)
   - Repository access: `Only select repositories` ובוחרים את `shopping-list`
   - Permissions → Repository permissions → **Contents: Read and write**
   - לוחצים Generate token ומעתיקים את הטוקן (מתחיל ב-`github_pat_`)
3. **בכל טלפון**: פותחים את הכתובת, לוחצים ⚙️, כותבים את השם שלכם ומדביקים את הטוקן. אחר כך "הוסף למסך הבית" כדי שהאפליקציה תיפתח כמו אפליקציה רגילה.

> הטוקן נשמר רק בטלפון ומאפשר לשנות **רק את הריפו הזה**. לא שולחים אותו לאף אחד חוץ מבן/בת הזוג.
